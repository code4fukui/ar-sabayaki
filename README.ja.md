# ar-sabayaki

さば焼きの3Dモデルを表示するAR（拡張現実）アプリ。

## デモ

https://code4fukui.github.io/ar-sabayaki/

## 機能

- さば焼きの3DモデルのAR表示
- さまざまな角度や距離からモデルを閲覧可能

## データ

- [さば焼きの3Dモデルデータ](data/)（提供: [Nihiki TEA TO GO](https://www.instagram.com/nihiki_teatime/)）
- [3Dプリンター用さば焼きver2の3Dモデルデータ](data/sabayaki2-hanmi.stl)
