# ar-sabayaki

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

Augmented Reality app to view a 3D model of Japanese fried mackerel.

## Demo

https://code4fukui.github.io/ar-sabayaki/

## Features

- AR display of 3D sabayaki (fried mackerel) model
- Ability to view the model at different angles and distances

## Data

- [3D model data for sabayaki](data/) provided by [Nihiki TEA TO GO](https://www.instagram.com/nihiki_teatime/)
- [3D model data for sabayaki ver2 for 3D printer](data/sabayaki2-hanmi.stl)
